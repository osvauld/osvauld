# Scribe Decomposition — LayerUnit

## Context

Scribe manages per-layer state across **4 scattered collections** in `ScribeState`:
- `layers: HashMap<String, Layer>` — LoroDoc instances
- `dirty_layers: HashSet<String>` — layers needing persistence
- `loro_subscriptions: HashMap<String, loro::Subscription>` — observer handles
- `local_only_layers: Arc<RwLock<HashSet<String>>>` — sync=false flags

Every operation touches 2-3 of these in coordinated fashion. This creates a maintenance burden and prevents per-layer lifecycle management (lazy loading, eviction). The decomposition consolidates all per-layer state into `LayerUnit` structs, making Scribe a thin router.

**Prerequisites complete**: Phase 2 (dynamic layers, two-tier permits, PermitIssuer trait, layer consent) is done. The `layer_unit/` module already exists with `dynamic.rs`.

## Design

### LayerUnit Struct

```rust
// scribe/src/layer_unit/mod.rs

/// Per-layer compute unit — owns all state for a single layer
pub struct LayerUnit {
    /// The CRDT document
    layer: Layer,
    /// Needs flush to storage?
    dirty: bool,
    /// sync: false in permit — never broadcast
    is_local_only: bool,
    /// Created via dynamic_layer_schema (not static template)
    is_dynamic: bool,
    /// Loro observer subscription (dropped = unsubscribed)
    loro_sub: Option<loro::Subscription>,
}
```

Key: Layer is `Clone` (confirmed at `loro_observer.rs:320`), so observer tasks get their own clone.

### LayerUnit API

```rust
impl LayerUnit {
    pub fn new(layer: Layer) -> Self;
    pub fn new_empty() -> Self;      // Layer::new()

    // Layer access
    pub fn layer(&self) -> &Layer;
    pub fn layer_mut(&mut self) -> &mut Layer;  // for in-place ops if needed

    // Dirty tracking
    pub fn mark_dirty(&mut self);
    pub fn is_dirty(&self) -> bool;
    /// Export snapshot if dirty, clear flag. Returns None if clean.
    pub fn take_dirty_snapshot(&mut self) -> Option<Vec<u8>>;

    // Metadata
    pub fn is_local_only(&self) -> bool;
    pub fn set_local_only(&mut self, val: bool);
    pub fn is_dynamic(&self) -> bool;

    // Observer lifecycle
    pub fn has_observer(&self) -> bool;
    pub fn set_observer(&mut self, sub: loro::Subscription);
    /// Drop the observer (unsubscribes from Loro)
    pub fn clear_observer(&mut self);
}
```

## Mechanical Transformation Rules

Every access site follows one of these patterns:

| Before | After |
|--------|-------|
| `state.layers.get(name)` | `state.units.get(name).map(\|u\| u.layer())` |
| `state.layers.get_mut(name)` | `state.units.get_mut(name).map(\|u\| u.layer())` |
| `state.layers.contains_key(name)` | `state.units.contains_key(name)` |
| `state.layers.insert(name, Layer::new())` | `state.units.insert(name, LayerUnit::new_empty())` |
| `state.layers.insert(name, layer)` | `state.units.insert(name, LayerUnit::new(layer))` |
| `state.layers.keys()` | `state.units.keys()` |
| `state.layers.entry(name).or_insert_with(Layer::new)` | Unit entry pattern (see below) |
| `state.dirty_layers.insert(name)` | `state.units.get_mut(name).unwrap().mark_dirty()` |
| `state.dirty_layers.drain()` | iterate `units.iter_mut()`, check `take_dirty_snapshot()` |
| `state.dirty_layers.is_empty()` | `state.units.values().all(\|u\| !u.is_dirty())` |
| `state.dirty_layers.remove(name)` | `state.units.get_mut(name).map(\|u\| u.clear_dirty())` |
| `state.loro_subscriptions.contains_key(name)` | `state.units.get(name).map(\|u\| u.has_observer()).unwrap_or(false)` |
| `state.loro_subscriptions.insert(name, sub)` | `state.units.get_mut(name).unwrap().set_observer(sub)` |
| `state.loro_subscriptions.len()` | `state.units.values().filter(\|u\| u.has_observer()).count()` |
| `state.local_only_layers` (all refs) | Removed — use `unit.is_local_only()` |
| `state.mark_layer_local_only_if_needed(name)` | `unit.set_local_only(!state.should_sync_layer(name))` |

**Entry pattern** (used in `handle_update_from_json`):
```rust
// Before:
let layer = state.layers.entry(name).or_insert_with(Layer::new);
// After:
let unit = state.units.entry(name).or_insert_with(LayerUnit::new_empty);
let layer = unit.layer();
```

#[cfg(test)]
mod tests {
    use super::*;
    use domains::Layer;

    #[test]
    fn test_new_empty() {
        let unit = LayerUnit::new_empty();
        assert!(!unit.is_dirty());
        assert!(!unit.is_local_only());
        assert!(!unit.is_dynamic());
        assert!(!unit.has_observer());
    }

    #[test]
    fn test_new_with_layer() {
        let layer = Layer::new();
        let map = layer.loro().get_map("test");
        map.insert("key", "value").unwrap();
        layer.commit();

        let unit = LayerUnit::new(layer);
        // Layer data preserved
        let content = unit.layer().to_json();
        assert!(content.get("test").is_some());
    }

    #[test]
    fn test_dirty_tracking() {
        let mut unit = LayerUnit::new_empty();
        assert!(!unit.is_dirty());
        assert!(unit.take_dirty_snapshot().is_none());

        unit.mark_dirty();
        assert!(unit.is_dirty());

        let snapshot = unit.take_dirty_snapshot();
        assert!(snapshot.is_some());
        // Flag cleared after take
        assert!(!unit.is_dirty());
        assert!(unit.take_dirty_snapshot().is_none());
    }

    #[test]
    fn test_dirty_snapshot_contains_data() {
        let mut unit = LayerUnit::new_empty();
        let list = unit.layer().loro().get_list("items");
        list.push("hello").unwrap();
        unit.layer().commit();
        unit.mark_dirty();

        let snapshot = unit.take_dirty_snapshot().unwrap();
        // Snapshot can be used to reconstruct layer
        let restored = Layer::from_snapshot(&snapshot).unwrap();
        let content = restored.to_json();
        assert!(content.get("items").is_some());
    }

    #[test]
    fn test_local_only_flag() {
        let mut unit = LayerUnit::new_empty();
        assert!(!unit.is_local_only());

        unit.set_local_only(true);
        assert!(unit.is_local_only());

        unit.set_local_only(false);
        assert!(!unit.is_local_only());
    }

    #[test]
    fn test_dynamic_flag() {
        let mut unit = LayerUnit::new_empty();
        assert!(!unit.is_dynamic());

        unit.is_dynamic = true;
        assert!(unit.is_dynamic());
    }

    #[test]
    fn test_observer_lifecycle() {
        let mut unit = LayerUnit::new_empty();
        assert!(!unit.has_observer());

        // Create a real Loro subscription
        let sub = unit.layer().subscribe_root(|_| {});
        unit.set_observer(sub);
        assert!(unit.has_observer());

        unit.clear_observer();
        assert!(!unit.has_observer());
    }

    #[test]
    fn test_clear_dirty() {
        let mut unit = LayerUnit::new_empty();
        unit.mark_dirty();
        assert!(unit.is_dirty());

        unit.clear_dirty();
        assert!(!unit.is_dirty());
    }
}

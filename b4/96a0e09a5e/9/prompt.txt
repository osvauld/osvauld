## Context

**Phases 1-2 complete**: LayerUnit has rich per-subscriber state with capabilities (Phase 1), and `GrantType::Role` has been replaced with `GrantType::Open` (Phase 2). All 100 unit tests pass. 6/8 integration tests pass.

**Two tests still failing** (pre-existing, not regressions):
- `test_viewer_writes_to_dynamic_channel` — viewer writes msg2, node/owner never receive it
- `test_dynamic_channel_late_joiner` — viewer joins after channel exists, never discovers msg1

**Root cause**: Timing race between separate `LayerPermit` and `SyncOffer` messages. Currently:
1. Node sends `LayerPermitMsg` (permit only, no data) to viewer
2. Node's Scribe broadcasts `SyncOffer` (data only, no permit) to viewer
3. These arrive independently and race:
   - If `LayerPermit` arrives before data → `AuthorizeLayerSubscriber` fires but LayerUnit doesn't exist yet → **silently dropped**
   - If data arrives before `LayerPermit` → layer created but node not authorized as subscriber on viewer's Scribe → **viewer writes never reach node**
4. Late joiners: no mechanism to send LayerSync for pre-existing dynamic layers on connection

**Fix**: Bundle data + permit in a single `LayerSync` message. Viewer processes both atomically — creates layer, stores permit, authorizes subscriber, sends consent. No race.

## Design: LayerSync + LayerConsent

### New wire messages

```
LayerSync  (0x0600):  request_id, page_id, layer_name, layer_type, data, state_vector, ephemeral_public, permit
LayerConsent (0x0601): request_id, page_id, layer_name, consent_permit
```

### Remove (after migration)
```
LayerPermitMsg       (0x0205) → replaced by LayerSync
LayerConsentGrantMsg (0x0502) → replaced by LayerConsent
LayerConsentAckMsg   (0x0503) → no separate ack needed
```

### Keep unchanged
```
SyncOffer/SyncAccept/SyncAck — Ongoing 3-step delta sync
SyncReset/SyncSnapshot — Resync fallback
SyncConsentGrant/SyncConsentAck — Space/page level consent (handshake)
```

### Flow: Dynamic layer (open grant)

```
Owner                     Node                         Viewer
  │                         │                              │
  │ SyncOffer (data +       │                              │
  │   authority_permit)     │                              │
  ├────────────────────────>│                              │
  │                         │ detect dynamic schema        │
  │                         │ issue layer permits          │
  │                         │ export layer snapshot        │
  │                         │                              │
  │                         │ LayerSync (data + permit)    │
  │                         ├─────────────────────────────>│
  │                         │                              │ decrypt data
  │                         │                              │ store permit
  │                         │                              │ apply to Scribe (creates layer)
  │                         │                              │ authorize node as subscriber
  │                         │                              │
  │                         │        LayerConsent          │
  │                         │<─────────────────────────────┤
  │                         │ store consent                │
  │                         │ authorize viewer on Scribe   │
  │                         │                              │
  [Ongoing: SyncOffer/SyncAccept/SyncAck for incremental delta sync]
```

### Flow: Late joiner

```
1. Viewer connects, handshake completes
2. Node subscribes viewer to page → Scribe.handle_subscribe()
3. Scribe.issue_pending_layer_permits() detects existing dynamic layers
4. Emits SyncEvent::LayerAccessChanged for each
5. Coordinator → PeerActor → export snapshot → send LayerSync
6. Viewer processes LayerSync atomically (same as above)
```

### Flow: Viewer write-back (fixed)

```
After LayerSync + LayerConsent exchange:
  - Node IS a subscriber on viewer's dynamic LayerUnit ← set during LayerSync processing
  - Viewer IS a subscriber on node's dynamic LayerUnit ← set during LayerConsent processing

1. Viewer writes locally → Loro observer → broadcast_update()
2. Node subscriber receives BroadcastPayload → PeerActor → SyncOffer to node
3. Node applies → broadcasts to owner (existing SyncOffer flow)
```

     ///
     /// **Sync-target auto-subscription**: When a new syncable layer is created and we have
     /// a sync_target (owner/viewer mode), the sync_target is auto-added as subscriber.
     /// This ensures new dynamic layers propagate to the node via the normal CRDT observer

     fn ensure_layer_exists(state: &mut ScribeState, layer_name: &str) -> bool {
         let is_new = !state.units.contains_key(layer_name);
         if is_new {
             let mut unit = LayerUnit::new_empty();
             unit.set_local_only(!state.should_sync_layer(layer_name));
             state.units.insert(layer_name.to_string(), unit);
     
             // Auto-subscribe sync_target to new syncable layers
             auto_subscribe_sync_target(state, layer_name);
     
             debug!(layer = %layer_name, "Created new layer");
         }

     /// Auto-subscribe the sync_target to a newly created syncable layer.
     ///
     /// **Context**: Owner/viewer creates a new layer. The sync_target (node) needs to
     /// receive data for it. By adding them as subscriber, the Loro observer broadcasts
     /// will include them, and the PeerActor sends SyncOffer to the node.
     fn auto_subscribe_sync_target(state: &ScribeState, layer_name: &str) {
         if !state.should_sync_layer(layer_name) {
             return;
         }
     
         let sync_target_did = match state.sync_config.as_ref() {
             Some(cfg) => match cfg.sync_target.as_deref() {
                 Some(did) => did.to_string(),
                 None => return,
             },
             None => return,
         };

             subs.iter()
                 .find(|((d, _), _)| d == &sync_target_did)
                 .map(|(_, info)| info.broadcast_tx.clone())
         });

             let caps = crate::layer_unit::Capabilities { read: true, write: true, sync: true };
             unit.add_subscriber(sync_target_did.clone(), caps, tx);
             debug!(layer = %layer_name, target = %sync_target_did, "Auto-subscribed sync_target to new layer");

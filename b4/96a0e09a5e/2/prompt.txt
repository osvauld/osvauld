  Add event_id or seq for ordering:

  Timestamps have millisecond resolution. Multiple events happen in the same millisecond (e.g.,
  the node emitting 3 authorized_dynamic_permit events all at 1770827302323). A monotonic
  sequence number per instance would make ordering unambiguous.

  Add phase tag for grouping:

  Events naturally cluster into phases. A tag like:
  - "phase": "handshake" — Hello, Welcome, SyncOffer, SyncAccept during initial connect
  - "phase": "dynamic_layer" — NewDynamicLayer, LayerPermit, LayerConsent
  - "phase": "steady_state" — regular SyncOffer/Accept during ongoing operation

  This would let you filter grep '"phase": "dynamic_layer"' to see just the channel creation
  flow.
